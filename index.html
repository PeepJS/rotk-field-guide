ROTK field guide

Return of the King is an independent, non-commercial H1Z1: King of the Kill / Z1 Battle Royale server emulator. It rebuilds the missing server side and talks to a client you already own. It does not own H1Z1, and it does not redistribute the game.

What ROTK is

Online games need a client and a server. ROTK rebuilds authentication, worlds, players, inventories, combat, matchmaking, and game rules so a legitimate Z1 Battle Royale install can talk to community servers again.

Z1 Battle Royale is still a live Daybreak service on Steam. ROTK is an unauthorized emulator of that live title, not a revival of a shut-down game. See Legal.

“We are not recreating the H1Z1 client. We are building a server capable of communicating with it.” — rotk.app/project

They build

Server software and web services: accounts on rotk.app, launch tickets, zone/login, MOTD gateway, voice grants, attestation.

They connect to

Your existing H1Z1 / Z1BR client (build 1.0.326.439939, also called BR1315). Client code, art, audio, and names stay Daybreak’s.

Stance

Independent preservation. No paid access or pay-to-win. Discord About-the-project also lists exclusive cosmetics for tournament and league wins.

About the project

Transcribed from the ROTK Discord channel About-the-project (2026-08-31). Fan copy of their own words, not a statement from this guide’s author.

The stated goal is to bring back a passionate H1Z1 community and revive the golden era of the Battle Royale. They say they use modern AI tooling and github.com/H1emu as a reference.

Population is no longer large enough for endless full Solo, Duo, and Fives lobbies. For now they focus on tournaments, competitive leagues, and community events. They note that private servers already exist on the official game; ROTK’s stated aim is to go further with community features.

Events

Tournaments, competitive leagues, and fun community events while match volume is low.

Modes & rules

Return of Showdown. Custom modes such as Red vs Blue with auto-built teams. Custom gas timings, moving safe zones, new POIs, more later.

Client & extras

Runs on the Z1BR client while they work to restore early-season assets, animations, and content. Tournament cosmetics. Enhanced anti-cheat.

How to play

ROTK does not download H1Z1. You need Z1 Battle Royale on Steam. The launcher copies that install into an isolated folder (often C:\Games\ROTK) and never writes back into steamapps.

StepDetail
1. AccountSign in with Steam on rotk.app. Avatar → Account settings → generate a 32-character launcher key.
2. LauncherInstall ROTK Launcher 1.4.2 (Windows 10/11 x64). Paste the key. It is stored with Windows DPAPI, not in ClientConfig.ini.
3. ClientPoint at Steam Z1BR as the copy source, or adopt an already-isolated client. Expected exe: H1Z1.exe BR1315 / 1.0.326.439939.
4. PlayLauncher fetches a one-time ticket over HTTPS, writes ClientConfig.ini, syncs asset packs, then starts H1Z1.exe with ROTK arguments.

Player and admin keys are different ROTK accounts. The launcher keeps four slots (GAME 2 / TEST × player / admin). An unconfigured launcher always defaults to GAME 2, never test.

Launch order

  1. HTTPS ticket from rotk.app
  2. Optional GitHub asset sync
  3. Write ClientConfig.ini (servers, local Steam gateway, :8080 URIs)
  4. Deploy / verify vivoxsdk_x64.dll proxy + Vivox 5 + rotk-crouch-parity.ini
  5. Attest install hashes to the backend
  6. Spawn H1Z1.exe
  7. Client HTTP to :8080, then UDP login, then zone transfer

Servers

The launcher hard-codes two bounded contracts. Picking a server switches gateway, login, website, tickets, and attestation together.

GET https://rotk.app/api/status returns players, capacity, online, and sampledAt. The launcher footer polls both GAME 2 and TEST every 60s. Names are not public. In-match nametags are the only player-visible identity besides your own logs.

Launcher 1.4.2 (2026-08-17)

Electron + React, EN/FR, GPL-3.0-or-later. Copies from Steam with SHA-256 checks. Remembers install in %APPDATA%\ROTK Launcher. Native bits: steam_api64.dll shim (Zig 0.15.2) and a Vivox 5 proxy that also carries crouch parity v12.

Crouch patch

The hook lives in vivoxsdk_x64.dll so H1Z1.exe is never patched on disk. It only activates in memory on the exact BR1315 hash/PE. It replaces crouch pose blend weight; camera hook stays off to protect ADS. v12 uses a 256-entry animation-network cache for crowded Solos. Files are verified at install, adopt, pre-attestation, and immediately before spawn.

Auth flow

Steam on rotk.app → 32-char key → launcher POST over HTTPS → one-time ticket + ROTKID + GameAccountGUID + SteamID + name. Client only sees the short ticket via localhost gateway. Durable key is not written into ClientConfig.ini.

Launcher rules: HTTPS GitHub only. SHA-256 + exact size. No exe/dll/scripts. Cannot overwrite H1Z1.exe, ClientConfig.ini, steam_api64.dll. Zip entries must use /. Max 3 GB per asset, 8 GB total. feed.json and asset-payloads.v1.json must be committed together or attestation root_mismatch follows.

Integrity attestation

Before a launch ticket is consumed, the launcher proves the install is the signed base manifest plus the official asset-payload hashes. That exists so client-side cheats like stripping smoke assets are visible to the backend.

FileJob
base-manifest.v1.jsonSHA-256 of a clean BR1315 tree (563 files). Server folds this into the expected root.
asset-payloads.v1.jsonSHA-256 of the unpacked .pack2 files after install. Must match the live feed.
feed.jsonWhat launchers download. URLs, zip hashes, versions.

UserOptions.ini (graphics/audio) and InputProfile_User.xml are excluded from the root so settings do not fail attestation.

Legal

Fan analysis of public contracts and statutes, not legal advice. No court has ruled on ROTK. Daybreak has already sued a similar live-service emulator and won a federal preliminary injunction.

Z1 Battle Royale (Steam app 433850) is still published by Daybreak Game Company and still has official servers. Steam still lists concurrent players in 2026. That is a live service. ROTK points a licensed copy of that same client at unofficial login, gateway, and zone hosts. “We do not redistribute H1Z1.exe” and “non-commercial” do not make that lawful. You do not own the client; Daybreak licenses it, and the license ends if you use it this way.

Daybreak Terms of Service

The Daybreak Terms of Service (retrieved 2026-08-31) forbid the entire ROTK stack in plain language. Players agree not to:

  • Attempt to play any Daybreak Game on any server that is not controlled or authorized by Daybreak or its designees.
  • Create, use or provide any server emulator or other site where any Daybreak Game may be played, or post or distribute emulators or related tools without Daybreak’s written permission.
  • Modify any part of any Daybreak Game, including any client and/or server.
  • Attempt to disable or circumvent measures that restrict access to accounts, servers, databases, data, computers, and networks.
  • Decrypt or modify data transmitted between the game software and Daybreak’s game servers.
  • Use any Daybreak Game in connection with commercial activity, including e-sports or group competition, without prior written consent — which covers advertised tournaments and leagues.

The license grant is explicit: the client-side software may not be “used as a stand-alone game (without connecting to Daybreak’s game servers), or used in connection with non-Daybreak game servers.” Breach automatically terminates the ToS and EULA. You are then required to stop playing and delete the software. That is the contract position for every ROTK player and operator, not a gray area.

Daybreak EULA

The End User License Agreement is narrower still. Section 4 says any use outside the license infringes Daybreak’s copyrights. It specifically bans:

  • 4.2 reverse engineering, decompiling, or reconstructing protocols, file formats, or interfaces.
  • 4.3 creating, facilitating, hosting, or linking to play through “interception, emulation or redirection of the communication protocols used by Daybreak,” including protocol emulation, tunneling, packet sniffing, and utility programs — “unauthorized network play over the Internet.”
  • 4.4 creating, facilitating, or maintaining any unauthorized connection to any Game.
  • 4.5 mining, decrypting, or modifying data between client and server.
“PLEASE NOTE THAT UNAUTHORIZED USE OF THE DAYBREAK PROPERTY MAY SUBJECT YOU TO MONETARY DAMAGES AND OTHER CIVIL AND CRIMINAL PENALTIES, INCLUDING, WITHOUT LIMITATION, FOR COPYRIGHT INFRINGEMENT.” — Daybreak EULA § 3.1

ROTK’s public design is protocol emulation plus a launcher that writes unofficial servers into ClientConfig.ini and starts H1Z1.exe against them. That is the conduct 4.3 and 4.4 name. Copying the Steam tree into an isolated folder does not create a new license. It is still Daybreak’s client, used with non-Daybreak servers.

Copyright and the DMCA

ToS is a contract. Copyright and the Digital Millennium Copyright Act are federal law. Daybreak owns the Forgelight client, art, animations, maps, audio, names, and the service those assets were built to talk to. A third-party login/zone that reproduces that service so the copyrighted client will run is a derivative, unauthorized public performance of the game. “We wrote our own server” does not give you the right to host H1Z1. “Players already bought it on Steam” licenses play on Daybreak’s servers, not yours.

In Daybreak Game Company LLC v. Takahashi (S.D. Cal. No. 3:25-cv-01489), Daybreak sued operators of an EverQuest private server. The court granted a preliminary injunction in September 2025, finding likely copyright infringement and likely DMCA circumvention under 17 U.S.C. § 1201. The operators’ argument that they never connected to Daybreak’s servers did not save them: pointing the official client at an emulator, and distributing the tools to do it, was treated as bypassing the technological measures that control access to the copyrighted work. A consent judgment and permanent injunction followed in 2026.

ROTK is the same pattern on a title that is still live: isolate Daybreak’s client, replace authentication, emulate LoginUdp / zone protocols, ship a launcher and asset feed so other people can play. Abandoned-game preservation arguments do not apply while official Z1BR servers still exist.

What “non-commercial” does not do

Copyright infringement does not require a price tag. Daybreak’s ToS bans emulators with or without payment. Discord cosmetics and tournaments make the commercial overlay worse, not better.

Players are in the contract too

Launching through ROTK is playing on an unauthorized server and using an emulator. That terminates the Daybreak license and is grounds for account action on Steam / Daybreak. Operators carry the copyright and DMCA exposure of hosting it.

This page documents a live-service emulator. It is not permission to run one, play on one, or treat unofficial servers as legal because the official population is small.
